# Todo 앱 제품 요구사항 문서 (PRD)

**버전:** 1.0  
**작성일:** 2026-05-23  
**상태:** MVP 초안

---

## 1. 제품 개요

### 1.1 목적

개인이 할 일을 빠르게 기록하고 관리할 수 있는 경량 웹 기반 Todo 앱. 설치 없이 브라우저만으로 접근 가능하며, 복잡한 기능 없이 핵심 작업 관리에 집중한다.

### 1.2 대상 사용자

- 간단한 할 일 목록이 필요한 개인 사용자
- 별도 앱 설치 없이 브라우저에서 바로 쓰고 싶은 사용자

### 1.3 핵심 가치

| 가치 | 설명 |
|------|------|
| 단순함 | 최소한의 UI로 빠른 입력과 확인 |
| 즉시 사용 | 로그인·설치 없이 바로 시작 |
| 영속성 | 새로고침해도 데이터 유지 (localStorage) |

---

## 2. MVP 기능 범위

MVP는 아래 4가지 핵심 기능으로 구성된다.

| # | 기능 | 설명 |
|---|------|------|
| F-01 | Todo 생성 | 새 할 일 항목 추가 |
| F-02 | Todo 목록 조회 | 전체 할 일 목록 확인 |
| F-03 | Todo 수정 | 기존 항목의 내용 변경 |
| F-04 | Todo 삭제 | 항목 제거 |

완료 상태 토글(체크/언체크)은 MVP에 포함한다.

---

## 3. 사용자 스토리

### F-01: Todo 생성
> **As a** 사용자,  
> **I want to** 텍스트를 입력해 새 할 일을 추가하고 싶다,  
> **So that** 기억에 의존하지 않고 할 일을 기록할 수 있다.

**수락 기준**
- 입력 필드에 텍스트 입력 후 Enter 또는 추가 버튼을 누르면 목록에 추가된다.
- 빈 텍스트는 추가되지 않는다.
- 추가 후 입력 필드는 비워진다.

---

### F-02: Todo 목록 조회
> **As a** 사용자,  
> **I want to** 내 모든 할 일을 한 화면에서 보고 싶다,  
> **So that** 남은 작업을 한눈에 파악할 수 있다.

**수락 기준**
- 저장된 모든 Todo가 최신순으로 표시된다.
- 완료된 항목은 시각적으로 구분된다 (취소선 등).
- 항목이 없을 때는 빈 상태 메시지를 표시한다.

---

### F-03: Todo 수정
> **As a** 사용자,  
> **I want to** 기존 항목의 내용을 변경하고 싶다,  
> **So that** 잘못 입력했거나 내용이 바뀐 작업을 올바르게 유지할 수 있다.

**수락 기준**
- 항목의 편집 버튼(또는 더블클릭)으로 수정 모드 진입.
- 수정 중 Enter 또는 확인 버튼으로 저장, Escape로 취소.
- 빈 내용으로 저장하면 기존 내용이 유지된다.

---

### F-04: Todo 삭제
> **As a** 사용자,  
> **I want to** 더 이상 필요 없는 항목을 제거하고 싶다,  
> **So that** 목록이 깔끔하게 유지된다.

**수락 기준**
- 각 항목에 삭제 버튼이 있다.
- 삭제는 즉시 반영되며 별도 확인 팝업은 없다 (MVP).
- 삭제 후 목록이 즉시 갱신된다.

---

## 4. 기능 상세 요구사항

### 4.1 데이터 모델

```ts
interface Todo {
  id: string;          // UUID
  text: string;        // 할 일 내용 (1~200자)
  completed: boolean;  // 완료 여부
  createdAt: number;   // 생성 타임스탬프 (ms)
  updatedAt: number;   // 최종 수정 타임스탬프 (ms)
}
```

### 4.2 데이터 영속성

- `localStorage` 키 `todos`에 JSON 배열로 저장.
- 페이지 로드 시 자동으로 불러온다.
- 모든 변경(추가/수정/삭제/완료토글) 즉시 저장.

### 4.3 엣지케이스

| 상황 | 처리 방법 |
|------|-----------|
| 입력값이 공백만 있을 때 | 앞뒤 공백 제거 후 빈 문자열이면 추가 거부 |
| 200자 초과 입력 | 입력 필드에서 maxLength로 제한 |
| localStorage 용량 초과 | 에러 메시지 표시 (MVP에서는 단순 console.error 허용) |
| 빈 목록 | "할 일이 없습니다. 새 항목을 추가해보세요." 안내 문구 표시 |

## 6. UI/UX 요구사항

### 6.1 화면 구성 (단일 페이지)

```
┌─────────────────────────────────┐
│         Todo 앱                 │
├─────────────────────────────────┤
│  [입력 필드          ] [추가]   │
├─────────────────────────────────┤
│  전체 N개 · 완료 M개            │
├─────────────────────────────────┤
│  ☐  할 일 항목 1       [수정][삭제] │
│  ☑  할 일 항목 2       [수정][삭제] │  ← 취소선 표시
│  ☐  할 일 항목 3       [수정][삭제] │
└─────────────────────────────────┘
```

### 6.2 인터랙션 흐름

- **추가**: 텍스트 입력 → Enter 또는 [추가] 버튼 클릭 → 목록 상단에 추가됨
- **완료 토글**: 체크박스 클릭 → 즉시 완료/미완료 전환
- **수정**: [수정] 클릭 → 인라인 편집 모드 → Enter로 저장 / Escape로 취소
- **삭제**: [삭제] 클릭 → 즉시 제거

## 7. 기술 스택 제안

| 영역 | 선택 | 이유 |
|------|------|------|
| UI 프레임워크 | React 18 + TypeScript | 컴포넌트 재사용, 타입 안전성 |
| 스타일링 | Tailwind CSS | 빠른 UI 구현, 반응형 쉬움 |
| 상태 관리 | React useState / useReducer | 외부 라이브러리 불필요 |
| 빌드 도구 | Vite | 빠른 개발 서버, 간단한 설정 |
| 저장소 | localStorage | 백엔드 없이 데이터 영속성 확보 |
| 패키지 매니저 | npm | 기본 표준 |

## 8. MVP 제외 범위 (다음 단계)

아래 기능은 MVP 이후 단계에서 검토한다.

- 사용자 인증 (로그인/회원가입)
- 백엔드 API 및 데이터베이스 연동
- 태그 / 카테고리 분류
- 마감일 및 알림
- 드래그앤드롭 순서 변경
- 검색 및 필터링
- 다크 모드
- 팀 공유 / 협업 기능
